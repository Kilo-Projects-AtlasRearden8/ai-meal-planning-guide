09. FAQ & Glossary

Frequently asked questions

Do I have to pay?
No. All the tools and prompts in this guide work with free AI chat tiers. You never need a credit card.
Do I need to install anything?
No. A web browser and an internet connection are enough. The HTML site opens in any browser.
Can AI see what's in my fridge?
No. You have to tell it what you have. It cannot see photos unless the specific tool supports image upload — and even then, only share photos with no people, addresses, or private details in them.
Will the AI recipes actually work?
Mostly, but AI can make mistakes. Use common sense: if a recipe says "cook chicken for 2 minutes," that's wrong. Check food-safety basics (poultry to 165°F / 74°C).
Is this medical advice?
No. See the disclaimers throughout this guide. Talk to your doctor or a registered dietitian for medical diets.
Can I print the templates?
Yes. Use the printable HTML files in site/templates/, or print the Markdown pages directly.

Glossary

AI chat tool
A website or app where you type a message and get an answer back from an artificial intelligence.
Prompt
The message you type to an AI. A good prompt is clear and specific.
Hallucination
When an AI states something false as if it were true. Always double-check important facts.
Free tier
A version of a service you can use without paying, usually with some limits.
Pantry-first planning
Building meals around ingredients you already own, to reduce waste and spending.
Low-energy cooking
Meals that need little chopping, few dishes, and minimal standing time. Helpful for ADHD, chronic illness, or long work shifts.
