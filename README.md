# AI Meal Planning Guide

A beginner-friendly manual for using **free AI tools** to plan weekly meals from pantry ingredients, build grocery lists, honor dietary restrictions, and stick to a budget — with step-by-step prompts, printable templates, and plain-English privacy rules.

Brought to you by **Asdale Dynamics, LLC** — beginner-friendly AI education, books, and practical tools.  
Dylan Asdale, founder of Asdale Dynamics, LLC, is a registered nurse turned AI author. His book *The Massive AI Manual* and hub site dylanasdale.github.io explain AI "like a friend would": plain English, step by step, never condescending.

## What's inside

- **docs/** — the full beginner manual in Markdown
- **site/** — a static HTML version of the manual (no build step, no server required)
- **templates/** — printable weekly meal-plan and grocery-list templates
- **tests/** — a link/structure verification script

## Quick start

Read the manual in `docs/` or open `site/index.html` in any web browser. Nothing to install, nothing to sign up for, and nothing phones home.

## What this guide covers

1. Getting started with free AI chat tools
2. Turning pantry ingredients into a weekly menu
3. Building grocery lists from your menu
4. Cooking with dietary restrictions
5. Budget-friendly recipes
6. Step-by-step prompts you can copy and paste
7. Printable meal-plan templates
8. Privacy rules: what never to share with an AI
